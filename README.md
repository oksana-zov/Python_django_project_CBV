Питомник породистых кошек (Django CBV Project)

Веб-приложение для управления питомником кошек. 
Реализован каталог пород и животных, система отзывов с модерацией, 
личный кабинет пользователя и ролевая модель доступа.

1) После настройки виртуального окружения установите зависимости:
```bash
pip install -r requirements.txt
```
2) Заполните файл .env согласно .env_sample
3. Создайте базу данных MSSQL вручную:
   - Откройте SSMS (SQL Server Management Studio) или Azure Data Studio
   - Создайте новую базу данных с именем, указанным в `.env`
   - Убедитесь, что сервер запущен и доступен по адресу из `.env`
4) Создайте миграции:
```bash
python manage.py makemigrations
```
5) Проведите миграции:
```bash
python manage.py migrate
```
6) Создайте пользователей с разным уровнем доступа:
```bash
python manage.py ccsu
```
7) Заполните БД тестовыми данными:
```bash
python manage.py loaddata initial_data.json
```
8) ️Важно: Настройка медиа-файлов
Фикстуры содержат записи о кошках, но не сами файлы изображений.
Чтобы фотографии отображались корректно:
- Скачайте архив cats_photos.zip (приложен к проекту).
- Распакуйте его содержимое в папку media/cats/ вашего проекта.
- Убедитесь, что файлы лежат именно в media/cats/, а не во вложенной папке.
9) Запустите проект:
```bash
python manage.py runserver
```
Модели используемые в проекте:

Cats с полями:
- name - Кличка; breed - Порода; photo - Фотография;
- pedigree - родословная
- birth_date - Дата рождения;
- owner - Хозяин; views - Просмотры

Разрешения (Ролевая модель):
- Все пользователи: просмотр пород, кошек, опубликованных отзывов
- User: создание отзывов, редактирование своего профиля, добавление кошек
- Moderator: модерация отзывов (публикация/скрытие)
- Admin: полный доступ, управление контентом и пользователями

Реализованный функционал
- Регистрация и авторизация пользователей
- Личный кабинет с изменением данных и аватаром
- Каталог кошек с поиском и пагинацией
- Система отзывов с модерацией
- Счетчик просмотров (не учитывает владельца)
- Email-уведомления при регистрации и достижении 20 просмотров
- Кэширование списка кошек для оптимизации производительности
- Автоматическая цензура недопустимых слов в отзывах перед модерацией
